## 💌 my design philosophy

<div align="center">

> *"good design is when the user doesn't have to think. great design is when they smile."* 🌸

</div>

Every spacing decision, every color, every hover state — it's intentional. That's what separates a developer who codes from one who **builds experiences.** ✨
